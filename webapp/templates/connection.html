¿Cómo se creó este usuario?

El usuario y la base de datos se crean automáticamente al levantar el contenedor con podman/setup_podman.sh, mediante las variables de entorno POSTGRES_USER, POSTGRES_PASSWORD y POSTGRES_DB de la imagen oficial de PostgreSQL. Ese usuario es dueño de todas las tablas.

Si prefieres separar el usuario administrador del usuario que usa esta aplicación (buena práctica de seguridad), ejecuta el script sql/05_create_app_role.sql, que crea un rol con permisos limitados solo a lectura/escritura de datos (sin poder borrar tablas ni crear otras bases de datos), y actualiza webapp/.env con esas credenciales.
